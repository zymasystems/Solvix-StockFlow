# Solvix StockFlow Web

The PHP and MySQL website for Solvix StockFlow.

## Requirements

- PHP 8.0 or newer
- MySQL 8.0 or newer
- Apache or Nginx with PHP support
- Composer

## Local setup

1. Create a MySQL database and configure the connection for the web environment.
2. Install PHP dependencies with `composer install` from this directory.
3. Configure the required Firebase and environment settings. Keep credentials and `.env` files out of Git.
4. Serve this directory with Apache/Nginx or a PHP development server.

The Android app is maintained separately under `../mobile/`.
